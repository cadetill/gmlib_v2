# VCL CircleLab

Laboratorio visual para `TGMMap.Circles`, ya validado en VCL.

## Uso

1. Carga `GOOGLE_MAPS_API_KEY` si la tienes disponible.
2. Pulsa `Activate map`.
3. Ajusta `Center lat`, `Center lng` y `Radius (m)`.
4. Marca `Clickable`, `Draggable`, `Editable` y `Visible` segun quieras probar eventos.
5. Pulsa `Apply circle`.
6. Usa `Center map` o `Zoom to circle` para comprobar el encuadre.

## Controles

- `Load sample` restaura los valores de ejemplo.
- `Clear` elimina todos los circulos.
