# Common

Código compartido entre `VCL` y `FMX`.

Contenido actual:

- tipos base y wrappers comunes en `uGMLib.Core.*`
- `TGMMap` y routing Delphi <-> JavaScript
- serialización de `TGMMapOptions`
- colección `TGMMap.Markers`
- colección `TGMMap.InfoWindows`
- colección `TGMMap.Polylines`
- modelos de mensaje del bridge

Este directorio no depende de `TEdgeBrowser`, `TWebBrowser` ni de detalles concretos de framework.
